# FamilienHub

Private Familien-PWA für:

- persönliche Kalender + Familienkalender
- Aufgaben und wiederkehrende Aufgaben
- Einkaufslisten
- Wunschlisten
- besondere Anlässe
- Pinnwand
- Familienprofile
- Essensplanung
- Home-Assistant-Vorbereitung
- Supabase-Synchronisierung

## Deployment
